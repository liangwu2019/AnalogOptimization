# AnalogOptimization
This repository is for our submission "Arbitrarily Small Execution-Time Certificate: What was Missed in Analog Optimization". Currently, there are two paradigms for solving optimization problems: Numerical Optimization (solving optimization problems via digital computers) and Analog Optimization (solving optimization problems via Analog computers by transforming optimization problems into ordinary differential equations (ODEs)). Based on the rapid development of digital computers and decades of prosperity in Numerical Optimization theory, Numerical Optimization currently dominates.
